# Knapsak

Knapsak is a retail platform made of three apps that share one Firebase project:

- **knapsak_flutter** — customer app (Flutter) for browsing, ordering, and payments
- **knapsak_pos** — in-store point of sale (Vite + React)
- **knapsak_supplier** — supplier console (Vite + React) for catalogue and order fulfilment

Each directory is a standalone project. See the README inside it for how to run that app.
